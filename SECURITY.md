# Security policy

## Supported versions

Tessera is in an early rewrite and has no supported release. Only the current `main` branch receives fixes. Earlier `v0.1.0-alpha.*` builds are unmaintained.

## Reporting a vulnerability

Use GitHub's private reporting: [Report a vulnerability](https://github.com/redstone-md/tessera/security/advisories/new). Do not open a public issue for exploit details or sensitive information.

Include the affected commit, the Windows version and build, the expected impact and a minimal reproduction. Remove credentials, personal data and unrelated desktop content. There is no response-time commitment yet.

Please allow maintainers to assess a report and coordinate disclosure before publishing details.
