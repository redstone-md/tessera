# Code of Conduct

Tessera welcomes respectful collaboration from people of all backgrounds and experience levels. These expectations apply to issues, pull requests, reviews, and other project spaces.

## Expectations

- Discuss the code and the problem, not a person's worth or identity.
- Give specific, constructive feedback and accept good-faith disagreement.
- Respect privacy; do not publish personal information without permission.
- Do not harass, threaten, discriminate, or repeatedly disrupt discussions.
- Respect maintainers' decisions about scope and participation.

## Reporting and moderation

The repository is currently private. If you need to report misconduct, request a confidential conversation with a maintainer using an issue without naming other people or sharing sensitive details. Issues are visible to collaborators, so wait for a private follow-up before providing personal information.

Maintainers may edit or remove inappropriate content, close or lock discussions, or restrict participation. Before opening the repository publicly, maintainers must provide a working private contact route and update this policy. There is no response-time guarantee during early development.
