INDEPENDENT GRAPHICAL DERIVATION
The output window-close.svg was produced from the SVG font's U+EC84
outline, with fontTools 4.66.1 used only as an external source-analysis
tool. No font binary, SVG font, cmap, font converter or runtime font
subsystem is included in this asset directory.

The font outline was parsed into absolute pen commands and transformed:
  image x = font x * (24 / 1024)
  image y = (960 - font y) * (24 / 1024)
Affine matrix: (0.0234375, 0, 0, -0.0234375, 0, 22.5).
Every transformed point was independently rounded to three decimal places
in the 24 by 24 image coordinate system. Consecutive duplicate line
endpoints and explicit final line segments back to the contour start
were removed; SVG closePath supplies those closing segments. No control
point, curve type or shape was taken from a standalone SVG. The three
contours were serialized as one nonzero-fill path, with currentColor fill.
Maximum per-coordinate change from this font-only rounding:
0.0000390625 image units. Rounded output bounds: (2, 3) to (22, 21).
The unrounded SVG font bounds are approximately
(1.9999921875, 3) to (21.999984375, 20.9999765625).
Thus the raw fractional font path is not claimed to be mathematically
identical before normalization.

The pinned svg/regular/bx-window-close.svg was examined ONLY as a geometry
reference, not copied, transformed into the output or used to select
replacement coordinates. After independent three-decimal normalization
and redundant closure removal, all 28 canonical absolute commands and
all line/cubic control points match that reference exactly. This asserts
exact geometry of the normalized graphical output, not byte equality.
Reference:
https://raw.githubusercontent.com/atisawd/boxicons/9ffa9136e8681886bb7bd2145cd4098717ce1c11/svg/regular/bx-window-close.svg
Reference SHA-256: 12ec6006f23fe61dcef1591d1a85a9ef51480c3e8ed7a74bf87e4bb3663fecf7

TTF U+EC84 maps to uniEC84, glyph ID 904, with three contours and native
bounds (85, 64) to (939, 832). Its integer-rounded coordinates and
quadratic corner curves differ from the SVG font/reference. It is NOT
claimed to have exact reference geometry and is not the image source.
